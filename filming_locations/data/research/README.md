# 영화 촬영지 조사 자료

조사일: 2026-10-21. 이번 수집은 GMS 키나 GMS 호출을 사용하지 않았다.

## 확보 자료

- `kcisa_filming_20221125.csv`: 한국문화정보원의 공개 원본 15,034행. 영화 외 자료도 원본 보존을 위해 그대로 저장했다.
- `movie_rows_original.json`: `미디어타입=movie`인 원본 273행 전부.
- `curated_sources.json`: 별도로 조사한 공식기관·장소 운영사 안내와 사실 요약. 사진이나 웹 기사 전문은 복제하지 않았다.
- `quarantine.json`: 촬영지 혼동·배우 방문·역사 현장 등 4개 관계를 서비스 목록에서 보류한 근거.
- `manifest.json`: 건수, 원본 SHA-256, 다운로드 주소, 이용 조건, 범위.
- `priority_coverage.json`: 천만 관객급 유명 영화 중심 조사 우선순위별 확보 현황. 흥행 순위나 관객수 집계 파일이 아니다.
- `pending_leads.json`: 아직 촬영 근거를 확인하지 못한 유명 영화의 후속 조사 후보.
- `collection_report.md`: 우선 조사 작품별 집계.

앱에서 사용하는 통합 목록은 상위 폴더의 `locations.json`이다. 장소 단위로 묶고, 각 작품 관계는 `relations`에 따로 보존했다.
등록된 모든 영화와 촬영 관계가 검증 완료된 것은 아니다. `verified_works`만 별도 문서로 확인한 작품이다.

## 원본과 이용 조건

한국문화정보원 / 공공데이터포털:
https://www.data.go.kr/data/15111405/fileData.do

포털은 CSV를 무료·이용허락범위 제한 없음으로 안내한다. 이는 추가 조사한 사이트의 기사·사진을 포괄하는 허가가 아니다.
원본은 2022년 작성 자료이며 포털 메타데이터 갱신일이 현재 운영 상태를 보증하지 않는다.
영업시간·휴무일·전화번호 등 원본 값은 원본 파일에만 보존하고 현재 안내값으로 승격하지 않았다.

## 확인 범위

- 장소의 촬영 관계와 관광지로서의 현재 개방 상태는 별개다.
- 서연의 집·초원사진관은 촬영 당시 시설과 현재 시설의 관계를 따로 기록했다.
- 군위 주소는 해당 군의 공식 안내에 근거해 수정했다. 다른 주소는 원본 표기일 수 있다.
- 위도·경도는 원본값이며 현장 위치를 개별 검증하지 않았다. 별도 조사 장소는 확인하지 못한 좌표를 비워뒀다.
- `wiki_title`은 검색 후보이며 실제 위키 문서 존재 여부를 확인한 필드는 아니다.
- 미술관·제작 시설·대학교·주거지는 촬영됐다는 이유로 자유로운 관람이 보장되지 않는다.
- 현재 목록은 국내 범위다. 전 세계 유명 영화와 모든 촬영 장소를 망라한 데이터가 아니다.

## 재생성

프로젝트 폴더에서 `python scripts/import_research.py`를 실행하면 로컬 원본과 별도 조사 자료로 목록·집계를 다시 생성한다.
네트워크나 GMS를 호출하지 않는다. 수동으로 locations.json만 수정하면 재생성 때 반영되지 않으므로,
추가 검증은 curated_sources.json에 기록한 뒤 재생성한다.
