# 제목과 글꼴 보완

메인 제목은 ‘여기 어디지?’로 사용한다. 명언 같은 홍보 문구를 피한다. Noto Sans KR을 기본으로 하고 400~800의 실제 두께를 불러온다. 작은 출처·안내는 13px 내외, 밝기 대비를 확보한다. 외부 글꼴이 불러와지지 않으면 맑은 고딕으로 표시한다.

# 최신 디자인 방향 (2026-10-22)

사용자의 JPL 홈페이지 참고와 ‘카리스마 있는 페이지’ 요청을 우선한다. 큰 영화 스틸, 검정·흰색, 절제된 붉은 강조, 굵은 한글 제목을 사용한다. 실제 슬레이트·필름 구멍을 크게 재현하는 장식과 둥근 외곽선은 제거한다. 제목은 힘 있게, 입력은 차분하고 명확하게 배치한다. 히어로의 영화 스틸은 기존 예시 이미지이며 출처 링크를 표시한다. 이미지 로드 실패 시에도 검은 바탕 위에 안내와 이동 링크가 남는다.

이전 취향 기록보다 이번 방향이 우선한다. 검색·검수·저장·출처와 좁은 화면의 세로 배치는 유지한다.

# 화면·문구 기준

사용자가 제공한 Scope_배포자료.md를 바탕으로 이 프로젝트에서 적용할 기준을 정리했다. 43개 자료를 전부 설치하거나 모든 규칙을 적용했다는 뜻은 아니다. 2026-10-22에 아래 3개 원문을 확인했다.

## 이 서비스의 방향

영화 장면을 보고 촬영지를 찾는 서비스다. 사용자가 요청한 슬레이트 입력 보드와 아날로그 필름 예시를 시각적 중심으로 삼는다. 물체의 줄무늬·격자·프레임·필름 구멍을 표현하되 입력·비교·출처 링크가 먼저 읽혀야 한다. 자료실과 검색 결과까지 모두 장식적인 보드로 감싸지 않는다.

## 색과 글자

슬레이트 #252d2a, 내부 입력 #343e38, 밝은 글자 #f4f0e5, 필름 바탕 #252b28, 필름 프레임 #f3ecdc, 강조 #927745. 사용자 선호인 고운돋움은 유지한다. 색이나 글꼴을 유행만 따라 바꾸지 않는다. 흐릿한 회색 안내문을 피하고 작은 출처도 읽을 수 있게 한다.

## 배치와 장식

큰 둥근 카드와 동일한 그림자를 모든 구역에 반복하지 않는다. 슬레이트는 입력 구획을, 필름 프레임은 예시 장면 하나를 묶는 데만 쓴다. 슬레이트의 SCENE/FRAME과 필름 번호는 실제 물체의 표현이므로 남길 수 있다. 그 밖의 장식용 대문자 영문 소제목·숫자·상투적인 문구는 줄인다. 자동 재생 애니메이션은 넣지 않는다.

넓은 화면에서는 입력 2칸·예시 3칸, 좁은 화면에서는 세로로 배치한다. 내용을 숨겨 가로 넘침을 감추지 말고 줄바꿈·칸 폭·여백을 먼저 고친다. 실제 브라우저로 확인한다.

## 한국어

사용자가 지금 할 행동을 짧고 구체적으로 말한다. 예: ‘영상 제목을 적고 캡처를 붙여넣으세요.’ 불필요한 감탄·과장·추상적 홍보 문장과 같은 안내의 반복을 줄인다. 자연스러운 기존 문장은 억지로 바꾸지 않는다. 사실·숫자·고유명사·출처·조건·미확인 여부는 그대로 보존한다. 화면 문구를 자연스럽게 고치는 것이 AI 사용 사실을 숨기거나 검증 수준을 부풀리는 일이 되어서는 안 된다.

## 동작과 접근성

키보드 초점이 보여야 하고 이미지에는 대체 텍스트, 입력에는 라벨, 비동기 상태에는 상태 안내가 있어야 한다. 장식용 클래퍼는 접근성 트리에서 제외한다. 일반 텍스트 붙여넣기를 막지 않는다. 이미지 붙여넣기는 요청된 핵심 기능이라 이미지인 경우에만 기본 붙여넣기를 대체한다. 취소는 복원할 수 있어야 한다. 장식보다 검색·저장·정정·출처 검증이 우선이다.
