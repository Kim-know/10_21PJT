## 추가 기능·비기능 검수

- [x] 로컬 임베딩/검색/지도에 GMS 토큰 사용 없음, 일일 한도·입출력 예산·캐시·자동 재시도 없음.
- [x] 검색 후보는 확인 전 미저장. “찾던 장소가 맞나요?” 검수 후 SQLite 영구 저장·중복 병합·벡터 갱신. 색인 실패 시 DB 기록 유지.
- [x] 좌표 별도 확인·좌표 없는 저장 지원. 250곳 표시, 미확보 16곳은 임의 좌표로 채우지 않음.
- [x] 지도 축소 시 밀집도/장소 수, 확대 시 작은 핀. 실제 핀 오죽헌 클릭 후 설명·주소·관련 작품 변경 확인.
- [x] 영상 정보/캡처 박스 동일 높이·폭, 좁은 화면 세로 배치. 독립 화면 데스크톱 두 박스 540×590.75, 모바일 가로 넘침 없음(375px).
- [x] 독립 화면 실제 클립보드 이미지 붙여넣기·미리보기·누락 안내·키 없음 503 안내 확인.
- [x] 수집 URL/리다이렉트의 공개 주소 검사, robots 허용 검사, 호스트 간격·캐시. 거부/정책 확인 실패 시 수집 차단.
- [x] 필수 의존성 고정, pip check 통과. 모델/키/DB/캐시는 ZIP에서 제외.
- [x] 출처·지도/폰트/모델 라이선스 기록 및 관련 고지 파일 포함.

`data/validation/test_results.json`: 8개 검사 모두 PASS, 실제 GMS 사용 false.

`rag_quality_comparison.json/md`: 5질문 평가 준비, 실제 GMS 미실행 명시.
`independent_library.png`, `independent_mobile.png`: 실제 화면.
`ui_verification.json`: 브라우저 검수 내역.
`output/package_report.json`, `output/package_smoke.json`: 검토 ZIP 무결성·제외 항목·압축 해제 실행 확인.

## 외부 확인이 필요한 항목

- 실제 GMS 연결, 장면 정답률, 실제 답변/인용 품질·전체 처리 시간은 이번 검수에서 제외.
- 다른 교육생의 상호 검수는 PEER_REVIEW.md 빈 양식 제공. 실제 검수자를 대신 작성하지 않음.
- 영화 예시 이미지의 공개 배포 허가는 확인되지 않음. 공개 전 허락 확보 또는 사용 가능한 이미지로 교체 필요. LICENSE_REVIEW.md 참조.

문서 292건은 설명자료 확보 수치이며 긴 본문 292개나 266곳의 독립 촬영 검증 완료를 의미하지 않는다. 다수 CSV 설명은 짧고 별도 촬영 관계 확인은 23곳이다.
