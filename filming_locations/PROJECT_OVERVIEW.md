# 프로젝트 주제

**영상 제목과 캡처로 촬영지를 찾아 검수하고 지도에 축적하는 RAG 서비스**

서비스명: **장면에서 여행으로**

## 주제 설명

영화·드라마·유튜브 등 영상의 제목과 배경 캡처를 입력하면, 이미지 속 단서와 외부 문서·기존 촬영지 자료를 대조해 장소 후보와 근거를 제공하는 서비스다. 사용자가 찾던 장소가 맞는지 검수하면 해당 정보를 DB에 저장하고, 확인한 좌표를 지도에 반영한다. 이렇게 축적한 장소 정보는 근거 기반 질의응답과 자연어 조건 탐색에 활용한다.

## 발표용 짧은 소개

“영상 속 마음에 든 장소를 캡처 한 장으로 찾아보고, 직접 확인한 장소를 지도와 지식 DB에 쌓아가는 서비스입니다.”

## 핵심 흐름

영상 제목·캡처 입력 → 시각적 단서와 문서 검색 → 근거가 있는 장소 후보 제시 → 사용자 검수 → DB·지도 반영 → 장소별 질의응답·조건 탐색

캡처만으로 모든 장소를 확정하는 서비스는 아니다. 근거가 부족하면 후보를 확정하지 않으며, 지도에는 확인된 좌표가 있는 장소만 표시한다.
