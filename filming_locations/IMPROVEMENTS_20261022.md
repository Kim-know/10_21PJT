# 촬영지 서비스 개선 결과 (2026-10-22)

## 1. 장면별 데이터와 정정

사용자 확인 DB의 JSON 레코드에 schema_version=2와 scenes를 추가했다. 각 장면은 작품·매체·회차/시점·설명·근거 문서 ID·시각 일치 상태·사용자 확인 상태를 가진다. 기존 기록에 필드를 강제로 요구하지 않아 이전 DB도 읽을 수 있다.

자료실에서 사용자 저장 장소의 이름·주소·지역을 정정하고, 저장 취소·복원을 할 수 있다. 원본 JSON은 수정하지 않는다. 이전 값·이유·시각을 review_revisions에 보존한다. 주소/장소명 변경 시 기존 좌표를 비우며, 좌표를 지정할 때에는 범위와 확인을 검사한다. 취소한 신규 장소는 지도·목록·검색에서 빠지고, 기본 장소에 합친 사용자 기록을 취소하면 기본 자료는 남는다. 기본 자료 자체 오류를 수정하는 기능과는 구분한다.

정정 후 벡터 갱신이 실패하면 기록을 보존하고 색인 대기로 표시한다. 불일치한 메타데이터와 취소된 사용자 근거는 답변에 사용하지 않는다. 자료실의 기본 자료 갱신으로 복구할 수 있다. 정정 뒤 이전 문서·대화가 새 기록에 붙지 않게 초기화한다.

## 2. 본문 확보 확대

기존 질문 기반 수집은 LLM 검색어 추출·문서 선별을 유지하면서 검색어당 결과 기본 3→5개, 후보 상한 8→15개, 선택 본문 상한 3→5개로 늘렸다. .env.example의 RESEARCH_* 설정으로 조정할 수 있다. 완료된 수집을 자동 재실행하지 않는다.

기존 공식 출처의 긴 본문을 GMS 없이 별도 수집하는 대기함을 추가했다. robots와 공개 URL 검사를 유지하고, 접근 실패·짧은 본문·성공을 구분한다. 본문 변경 시 승인 상태를 되돌려 재검토한다. 승인한 본문만 외부 문서 컬렉션에 색인한다.

실제 확보: 장소별 본문 7개, 고유 URL 5개, 합계 29,666자, 승인 0개/검토 대기 7개. 이는 새 촬영지 7곳이나 기관 검증 완료 7건이라는 뜻이 아니다. 기본 266곳/292청크는 대기 자료 승인 전에는 그대로다. 원문은 data/research_documents.sqlite3에 로컬 보관하며 검토 ZIP과 Git에서 제외한다. 패키지를 다른 PC에서 풀면 수집 버튼으로 다시 확보해야 한다. 제목·URL·글자 수는 data/validation/enrichment_inventory.json에 기록했다.

## 3. 키워드+의미 결합 검색

기존 유사도·MMR 외에 hybrid 옵션을 추가했다. 선택 장소의 문서에서 로컬 BM25 방식 키워드 순위와 의미 벡터 순위를 RRF로 합친다. 정확한 장소명·회차 같은 단어를 보완하며 외부 모델/API를 추가 호출하지 않는다. 메타데이터 상시 포함·장소 필터·Top-k·출처 번호는 유지한다. LangGraph는 retrieve/generate 두 노드를 유지한다. 기본값은 기존 유사도 검색으로 두었다.

## 4. 실패 후 추가 단서

같은 영상과 캡처에서 회차·대사·주변 풍경 단서를 200자까지 추가할 수 있다. 기존 이미지 분석과 이전 검색 자료 일부를 재사용하고, 새 텍스트 검색 후 후보를 다시 검토한다. 이미지 해시와 작품/매체/채널이 달라지면 재사용을 거부한다. 새 최종 후보 검토는 최대 1회 GMS 호출하며 누적 설명은 기존 300자 제한을 따른다. 실패하면 기존 결과는 유지한다.

## 5. 비교와 검수

23개 기존 공식 근거를 대상으로 검색 방식을 비교했다. 유사도 23/23, MMR 22/23, 결합 23/23으로 기존 공식 원문을 다시 찾았다. 내부 근거 검색 평가이며 실제 장면 인식률·답변 정확도·독립 사용자 질문 성능이 아니다. 첫 방식에 모델 초기화 비용이 있어 표시된 평균 시간으로 속도 우열을 결론내리지 않는다. 비교 파일은 data/validation/retrieval_benchmark.json/md다.

전체 검사와 브라우저 확인은 data/validation/test_results.json 및 improvements_queue.png를 참고한다. 실제 GMS 호출은 하지 않았다. 기존 scripts/compare_rag.py의 5질문 실제 답변 비교는 별도 명시 실행이 필요하다.

## 규칙 보존

F2001~F2012의 기본 흐름과 F2013 독립 화면, F2014 MMR을 유지했다. 메타데이터/외부 문서 컬렉션 분리, LangGraph 두 노드, LLM 검색어·선별·생성, 실제 인용 출처 표시, 대화 분리, 조건 탐색, 키/오류 비노출, 일일 호출 제한과 외부 정책 검사를 유지한다. 사용자 확인을 공식 검증으로 승격하지 않는다. 실제 GMS 품질·수업 상호 검수·예시 이미지의 공개 사용 허가는 여전히 별도 확인 대상이다. 본 개선이 심사자의 결격 없음 판정을 대신하지 않는다.

## 사용 위치

- 캡처 후보 확인 후 저장: 회차/장면 설명 입력.
- 자료실: 사용자 저장 장소 선택 → 정정/취소. 취소 기록 복원도 제공.
- 자료실: 공식 출처 본문 보강·검토 대기함 → 수집/원문 확인/승인 또는 제외.
- 근거 검색 방식: 키워드+의미 선택.
- 장면 검색 결과: 검색 결과에 단서 추가하기.
- 비교: python scripts/benchmark_retrieval.py (GMS 사용 없음).

Streamlit과 독립 API 화면 모두 구현했다. 실행 중인 서버는 변경 코드를 읽도록 재시작한다. .env 키 값은 변경하지 않았다.
